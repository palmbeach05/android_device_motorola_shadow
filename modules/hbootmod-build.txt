hbootmod source builds

From the configured Android build root after lunch:

  make HBOOTMOD_FROM_SOURCE=true hbootmod
  make HBOOTMOD_FROM_SOURCE=true systemimage

Keep HBOOTMOD_FROM_SOURCE=true on every source-build invocation. The default
packages bootstrap/modules/hbootmod.ko; source mode selects only the generated
module and does not fall back to the prebuilt on failure.

Source builds use the existing external-module Kbuild path, KERNEL_OUT and
KERNEL_MAKE_FLAGS. They wait for the kernel image build to prepare the kernel
output and symbol versions. sources/hbootmod/Makefile retains the object list.
Kbuild builds in sources/hbootmod/ and retains its incremental build state;
there is no separate source staging tree. The packaging input is
out/target/product/shadow/obj/HBOOTMOD/hbootmod.ko (adjust for PRODUCT_OUT).
The hbootmod target builds this input; systemimage installs it through the sole
PRODUCT_COPY_FILES recipe. Recursive collection excludes hbootmod from the
unrelated module destinations. Switching modes recopies the selected input
without forcing hbootmod recompilation.

Validation

Successful compilation does not establish load compatibility with the stock
2.6.32.9 kernel. Verify platform headers, configuration, exports, vermagic and
symbol CRCs against the loading kernel; a matching release string is insufficient.
Record compilation and linking of all five objects and inspect the generated
module with the toolchain's readelf and host modinfo before hardware testing.

Compare the generated module with system/bootstrap/modules/hbootmod.ko and the
copies extracted from systemimage and target-files. Change a source, rebuild,
and verify recompilation and reinstallation. Rebuild without changes to check
incremental compilation. Switch to prebuilt mode and back and verify each
installed file. Force a compiler failure and verify systemimage fails without
copying the prebuilt. An old installed file can remain after a failure; do not
deploy it as the result of that build. Run git diff --check.

Recovery precautions

Retain the checked-in prebuilt. Omit HBOOTMOD_FROM_SOURCE or set it to false and
rebuild systemimage to restore prebuilt packaging; verify the installed copy.
Before device testing, prepare an independent bootloader/SBF restore route,
the correct stock image and host tools, and a known-good image with the prebuilt.
Bootstrap recovery alone is insufficient when testing the handoff module.
Verify loading without force-loading, normal and recovery handoffs, and serial
behavior in Android and TWRP. Record stock HBoot serial information first; do
not assume rmmod is supported.

This checkout lacks the complete Android/kernel build environment, matching
stock kernel inputs, ARM toolchain and hardware. Compilation, ELF/CRC checks,
real image packaging and hardware validation remain unverified until performed
in a suitable environment. Local dependency and packaging rule checks cannot
establish those results.
